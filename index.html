Télécharger BotReckless.exe

Si ton navigateur bloque le téléchargement (« BotReckless.exe n'est pas fréquemment téléchargé ») :
1. Dans les téléchargements, clique sur les trois points … à droite de BotReckless.exe.
2. Clique sur Conserver, puis Afficher plus → Conserver quand même.
3. Lance BotReckless.exe. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même.
C'est normal pour un petit programme non signé, et à faire une seule fois : ensuite le bot se met à jour tout seul.

Pour publier une nouvelle version : Paramètres → Mise à jour du bot.
